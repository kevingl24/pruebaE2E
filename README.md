# pruebaE2E

Automatización E2E del flujo **Contact Us** en **Automation Exercise** usando  
**SerenityBDD con Screenplay (Java)**.

Se valida:
- Navegación al sitio
- Diligenciamiento del formulario Contact Us
- Carga de archivos
- Manejo de alertas
- Confirmación del mensaje de éxito
- Retorno a la página Home

---

## 🚀 Tecnologías utilizadas

- Java 17+
- Gradle
- Serenity BDD
- Screenplay Pattern
- Cucumber
- JUnit
